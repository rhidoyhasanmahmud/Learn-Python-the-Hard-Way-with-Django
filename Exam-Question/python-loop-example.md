
**Problem: Create a Unique Name List Without Using set**

**Problem Statement**

You are given two lists containing student names.

Some names may appear in both lists, and some names may also appear more than once.

Your task is to create a new list that contains all unique names from both lists.

Important Rule

- You are not allowed to use the set data type.

You should solve the problem using:

- Lists
- for loop / while loop

For Example, Given Lists (You may input list value/predefined also acceptable)

batch_1 = ["Hasan", "Rahim", "Karim", "Nusrat", "Rahim", "Sakib"]

batch_2 = ["Nusrat", "Jannat", "Sakib", "Farhan", "Hasan", "Mim"]

Expected Output

["Hasan", "Rahim", "Karim", "Nusrat", "Sakib", "Jannat", "Farhan", "Mim"]

Note: Please solve the problem by yourself without using ChatGPT or any other AI tool.
