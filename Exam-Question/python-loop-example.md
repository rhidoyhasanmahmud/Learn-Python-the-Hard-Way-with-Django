## Problem 1: Create a Unique Name List Without Using `set`

### Problem Statement

You are given two lists containing student names.

Some names may appear in both lists, and some names may also appear more than once.

Your task is to create a new list that contains all unique names from both lists.

### Important Rules

- You are not allowed to use the `set` data type.
- Use a `for` loop or `while` loop.
- You may use predefined list values or take input from the user.

### Example Input

```python
batch_1 = ["Hasan", "Rahim", "Karim", "Nusrat", "Rahim", "Sakib"]

batch_2 = ["Nusrat", "Jannat", "Sakib", "Farhan", "Hasan", "Mim"]
```

### Expected Output

```text
["Hasan", "Rahim", "Karim", "Nusrat", "Sakib", "Jannat", "Farhan", "Mim"]
```

## Problem 2: Separate Numbers into Even and Odd Lists

### Problem Statement

You are given a list containing several integer numbers.

Your task is to go through the list and separate the numbers into two new lists:

- One list will contain all even numbers.
- Another list will contain all odd numbers.
- You also need to count the total number of even and odd numbers.

### Important Rules

- Use a `for` loop or `while` loop.
- Do not manually create the final even and odd lists.
- You may use predefined list values or take input from the user.

### Example Input

```python
numbers = [12, 7, 9, 20, 15, 8, 4, 11, 18, 3]
```

### Expected Output

```text
Even Numbers:
[12, 20, 8, 4, 18]

Odd Numbers:
[7, 9, 15, 11, 3]

Total Even Numbers: 5
Total Odd Numbers: 5
```
